## Getting Started

1. Choose a project from the directory above.
2. Read the project-specific README for its objective, available files, tools, and execution notes.
3. Download or clone the repository and use the project's native application (Excel, Jupyter, R, MySQL, Power BI, or Tableau) as appropriate.

```bash
git clone https://github.com/ElScara/data-science-playground.git
cd data-science-playground
```

Some projects are documentation or dashboard exports rather than fully reproducible pipelines. See each README for the relevant input data and environment requirements.

## Repository Purpose

This is an evolving applied analytics portfolio: a place to investigate datasets, test modeling approaches, develop decision-support tools, and document lessons from real business problems.
