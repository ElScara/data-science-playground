# 🎢 Data Science Playground 

Welcome to my analytical sandbox. Like a busy prep station behind a Michelin-starred dish, this repository is dedicated to the heavy lifting: the continuous experimentation, data engineering, and raw code that power my deployed analytical solutions.

## 🧰 What's Inside? 

This archive houses scripts, coursework, and experimental models across multiple disciplines, organized by technology and domain: 

* **📁 01_Excel_Business_Analytics:** Advanced spreadsheet modeling and corporate data analysis.
* **📁 02_Python_Basics:** Core programming, data wrangling, and exploratory data analysis.
* **📁 03_R_Programming:** Statistical computing and data science applications in R.
* **📁 04_SQL_Scripts:** Database querying, architecture, and data extraction techniques.
* **📁 05_Machine_Learning_Python:** Supervised and unsupervised learning models, including scikit-learn architectures. 
* **📁 06_PowerBI_and_Tableau:** Scripts and raw data supporting Microsoft Power BI (PL-300) and Tableau visualization workflows.
* **📁 07_Capstone_Projec:** Comprehensive exercises combining multiple frameworks to solve complex data challenges.

## ⚙️ Philosophy

Whether it is optimizing a workflow or uncovering hidden trends in a messy dataset, the best insights come from continuous experimentation. This playground is where theoretical concepts are transformed into applied code.
