# Regional Sales Performance Analysis | Tableau

## Project Overview

A Tableau-based analysis of **sales performance across geographic regions**, supported by a project brief, a collection of visualizations, and a written analysis report. The project focuses on communicating regional differences and making sales information easier to interpret for business decisions.

## Analytical Objectives

- Explore the distribution of sales performance across regions.
- Compare geographic segments using visual summaries.
- Highlight patterns and performance gaps that merit further investigation.
- Present the analysis in a concise visual and written format.
