# Regional Sales Comparison | Tableau

## Project Overview

This project explores **regional sales performance through comparative data visualization**. It is part of the [Tableau portfolio](../README.md) in the [Data Science Playground](../../../) repository.

The project brings together a brief, a set of visual outputs, and a written report to communicate regional sales comparisons and support business-oriented interpretation.

## Objectives

- Compare sales performance across geographic regions.
- Present regional differences through clear data visualizations.
- Use comparative analysis to identify patterns and areas that may warrant further investigation.
- Communicate analytical observations in a structured report.
